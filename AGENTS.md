# AGENTS.md

This repo contains one agent skill: **unstuck**, a communication coach for when someone doesn't know what to say or how to reply.

When the user needs help replying to or writing a message to another person (dating apps, texts, a breakup, friends, family, LinkedIn, recruiters, professors, managers, coworkers, clients), read and follow:

`skills/unstuck/SKILL.md`

Load the files in `skills/unstuck/references/` as that file directs.
